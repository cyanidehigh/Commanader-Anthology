# Anthology Android

This folder is reserved for the Java Android companion app.

It is not included in the root Gradle build yet. The first unified build slice
keeps Android out until the shared Java core boundary is stable enough to avoid
dragging old prototype dependencies into the new Anthology foundation.

Planned role:

- game tracker and life counter
- session-local win/loss telemetry
- light deck building
- sync bundle import/export
- shared Java core consumer
