# Mobile Companion
#type/product-surface #status/active #area/mobile

Links: [[DDS]], [[Commander Anthology]], [[CCBuilder]], [[areas/Cross Platform Sync]]

The Android app is a companion surface, not the full Commander Anthology
program.

It should provide:

- game tracker / life counter
- win/loss recording only when two or more players are using it together
- light deck building
- optional sync/linking with desktop Anthology

It should not try to carry the full desktop feature set.

Telemetry privacy rule: win/loss and tracker telemetry should only be shared
between users inside the same active session.
