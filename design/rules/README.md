Links: [[../DDS]], [[../KANBAN]], [[../Release Notes]], [[CAPABILITY_MATRIX]]

This folder tracks Commander Anthology rules work.

The purpose is traceability, not speed. Every rules implementation should be
able to answer:

- which rules document was used
- which rule numbers or sections support the behavior
- what Anthology actually implements
- what Anthology deliberately does not implement yet
- where the code lives
- which tests prove the behavior

## Source Documents

- Current root source: `MagicCompRules 20260807.docx`
- Historical root source: `MagicCompRules 20260227.docx`

The August 7, 2026 document is the default source for new work unless a later
root rules document is added and explicitly adopted.

## Rule Note Template

Each rules note should include:

- source document/date
- relevant rule references
- plain-English summary
- implementation status
- code links
- test links
- explicit unsupported cases
