# Brand Identity
#type/area #status/active #area/brand-identity #project/commander-anthology

Links: [[../DDS]], [[../sources/Legacy Software Study]]

## Purpose

Track the visual identity inherited from legacy CCBuilder / Commander Analyst.

## Accepted Source

The legacy software already contains a Cynful Studio logo and a matching
desktop/Android colour palette. These are source assets for Commander Anthology
unless a deliberate rebrand decision replaces them.

## Current Rule

- Preserve the legacy logo asset.
- Preserve the legacy gold, red, black, and warm parchment palette.
- Use the values recorded in [[../sources/Legacy Software Study]] as the first
  palette source when restyling the new Java desktop shell.
- Do not treat temporary shell styling as final brand direction.
