# Platform
#type/area #area/platform #status/draft

Links: [[../DDS]], [[../decisions/0002 Java Platform]]

Commander Anthology is moving toward:

- Java shared core
- Java desktop application for the full-spectrum Anthology experience
- Java Android companion app for game tracker/life counter, limited win/loss
  telemetry, and light deck building

Existing Kotlin/Compose CCBuilder and Python Commander Sim work remains working
legacy migration material until deliberately ported, bridged, or retired.
