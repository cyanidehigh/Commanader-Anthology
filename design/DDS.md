# Commander Anthology DDS
#type/dds #status/active #project/commander-anthology

## Purpose

This folder is the traceable design system for [[Commander Anthology]].

It is the advanced version of [[../HANDOFF|HANDOFF]]: the handoff explains the
current state, while this design folder records decisions, models, workflows,
and active work in a way that remains useful in default Obsidian.
