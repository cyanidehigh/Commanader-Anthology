# 0008 Desktop Full Spectrum Mobile Companion
#type/decision #status/accepted #area/platform

Links: [[../DDS]], [[../areas/Platform]], [[../Commander Anthology]], [[../Mobile Companion]]

## Decision

The desktop app is the full-spectrum Commander Anthology program.

The Android app is a companion app, not a full desktop replacement. It should
focus on:

- game tracker / life counter
- win/loss recording only when two or more players are using it together
- light deck building

## Consequences

- Full Anthology functionality belongs on desktop first.
- Mobile UX should stay lighter and faster.
- Cross-platform sync must support users who only use one platform.
- Telemetry-style win/loss data should only be recorded when multiple players
  are intentionally participating through the app.
