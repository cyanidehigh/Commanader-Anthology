# 0002 Java Platform
#type/decision #status/accepted #area/platform

Links: [[../DDS]], [[../areas/Platform]], [[../areas/Shared Core]]

## Decision

Commander Anthology will move toward Java for:

- shared core
- desktop application
- Android CCBuilder app

## Consequences

- Existing Kotlin/Compose CCBuilder work is a working legacy app/skeleton and
  migration source.
- Existing Python Commander Sim work is a working legacy simulation foundation
  and migration source.
- New shared business rules should be designed for Java unless a later decision
  changes this.
